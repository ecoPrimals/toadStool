### **WGSL Alignment Lessons Learned**

Key insight: `vec3<f32>` in WGSL has 16-byte alignment!
- Rust struct padding must match WGSL alignment
- Use `bytemuck::Pod` for safe layout
- Uniform buffers require careful padding

Example:
```rust
#[repr(C)]
#[derive(bytemuck::Pod, bytemuck::Zeroable)]
struct Params {
    value: f32,      // 4 bytes
    _padding: [f32; 7], // 28 bytes padding for vec3 alignment
}  // Total: 32 bytes
```
