### 2. Runtime Hardware Detection ⭐⭐⭐⭐⭐

**Discovery**: Linux `/sys` provides rich introspection

**Example**:
```rust
// Ask the system, don't assume
/sys/block/sda/queue/rotational  // 0 = SSD, 1 = HDD
/sys/class/net/eth0/speed        // 1000 = gigabit

// Derive realistic capabilities
if ssd { 500_000_000 } else { 150_000_000 }
```

**Impact**:
- Accurate for actual hardware
- Adapts to upgrades automatically
- No manual configuration needed
- Cross-platform with fallbacks

**Lesson**: "Detection beats configuration"

### 3. Multi-Strategy Discovery ⭐⭐⭐⭐⭐

**Discovery**: Try multiple detection methods

**Impact**:

- Works with different tooling
- Graceful when tools missing
- Future-proof architecture
