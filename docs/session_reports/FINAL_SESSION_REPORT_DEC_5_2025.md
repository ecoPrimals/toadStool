## 🎓 **LESSONS & PATTERNS**

### Capability-Based Dependencies
```rust
// ✅ Modern pattern (use this!)
dependencies: vec!["capability:pki".to_string()]

// ❌ Old pattern (don't use)
```

### Safe by Default
```rust
// Default: 100% safe
#[cfg(not(feature = "unsafe-fast-cache"))]
pub use safe_impl::SafeCache as Cache;

// Opt-in: Unsafe for performance
#[cfg(feature = "unsafe-fast-cache")]
pub use unsafe_impl::UnsafeCache as Cache;
```
