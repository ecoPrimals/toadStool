You want to host game servers (Minecraft, Valheim, etc.) for friends but:
- Don't want to pay monthly cloud hosting fees ($45-100/month)
- Need YOUR gaming to have priority over servers
- Servers waste resources when no one's playing
- Traditional: Manual start/stop, no priority system

**Better**: Let ToadStool manage it intelligently!

---

## 🚀 What This Demo Shows

1. **Host Multiple Servers** - Minecraft, Valheim, Terraria in containers
2. **Priority Management** - Your gaming > friend's servers
3. **Auto-Suspend** - Pause servers when no players (save resources)
4. **Auto-Resume** - Wake servers when friends connect
5. **Fair Allocation** - CPU/RAM shared fairly among servers

**Result**: Free hosting + personal priority + efficient resource use!
