# 🧠 AI Orchestration Showcase - Quick Summary

**One-Line**: ToadStool orchestrates local AI models and cloud APIs via Songbird messaging and Squirrel AI gateway for privacy-preserving, cost-optimized intelligence.

---

## 🎯 What It Shows (30 seconds)

```
User Request
     │
     ▼
ToadStool analyzes:
  - Privacy level (HIGH = local, LOW = cloud)
  - Complexity (SIMPLE = local, COMPLEX = cloud)
  - Cost sensitivity
     │
     ▼
Songbird routes to:
  - Local AI (Llama 3) → Private, fast, FREE
  - Cloud AI (Claude/GPT) → Powerful, paid
     │
     ▼
Result: Best of both worlds!
```
