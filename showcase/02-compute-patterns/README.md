# Compute Pattern Showcases — ARCHIVED (S169)

These demos reference JSON-RPC methods (`discovery.*`, `science.*`, `deploy.*`)
that were removed from toadStool in S169. The science relay was removed
(springs call barraCuda directly), discovery methods were simplified, and
deploy methods were transferred to biomeOS orchestration.

The demo code is preserved as a historical reference.

For current methods, see `compute.*`, `capabilities.list`, and `identity.get`
in the server API.
