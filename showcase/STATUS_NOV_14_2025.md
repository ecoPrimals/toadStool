## 🎯 SHOWCASE CAPABILITIES (v0.1.0 Beta)

### What You Can Do NOW:

```bash
# 1. Check system capabilities
./target/release/toadstool-cli capabilities
# Shows: System info in JSON format

# 2. Generate a biome manifest
./target/release/toadstool-cli init --template basic my-biome
# Creates: my-biome/biome.yaml

# 3. Validate a manifest
./target/release/toadstool-cli validate my-biome/biome.yaml
# Shows: Validation results, warnings, summary

# 4. Explore CLI commands
./target/release/toadstool-cli --help
# Shows: All 14 available commands

# 5. See beautiful ASCII art
./target/release/toadstool-cli
# Shows: ToadStool branding and info
```

### What Requires Server (Coming Soon):

```bash
# These work but need ToadStool server running:
./target/release/toadstool-cli run biome.yaml        # Start biome
./target/release/toadstool-cli up biome.yaml         # Background mode
./target/release/toadstool-cli ps                    # List running
./target/release/toadstool-cli logs biome-name       # View logs
./target/release/toadstool-cli down biome-name       # Stop biome
```
