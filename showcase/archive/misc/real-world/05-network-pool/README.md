# 🌐 Multi-ToadStool Network Showcase

**Your Computer + Friend's Computer = Distributed Supercomputer**

---

## 🎯 The Problem

- Big job takes 6 hours on your machine
- Friend's powerful machine is sitting idle
- Traditional: Complex distributed setup, manual coordination

**Better**: ToadStool instances discover and collaborate automatically!

---

## 🚀 What This Demo Shows

1. **Auto-Discovery** - Find friend's ToadStool via mDNS
2. **Capability Sharing** - See each other's GPUs, CPUs
3. **Job Distribution** - Split large jobs automatically
4. **Result Aggregation** - Combine results seamlessly
5. **Fair Exchange** - Track contributions both ways

**Result**: 6-hour job → 2.3 hours using friend's machine!

---

## 🎬 Quick Demo

```bash
cd real-world/05-network-pool
./demo.sh
```

Shows:
- Your PC: RTX 5090, 16 cores
- Friend's PC: RTX 3090, 32 cores (discovered)
- Job: 100 video renders (6h estimate single-machine)
- Distribution: 60% yours, 40% friend's
- Complete in 2.3 hours (62% faster!)
