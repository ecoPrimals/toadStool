```

    ↓

    │   │   └→ 🗄️ NestGate (stores encrypted)
    │   ├→ Epoch 4: checkpoint (encrypted → stored)
    │   ├→ Epoch 6: checkpoint (encrypted → stored)
    │   ├→ Epoch 8: checkpoint (encrypted → stored)
    │   └→ Epoch 10: final model
    │       ├→ 🐻 BearDog (encrypts with AES-256-GCM)
    │       └→ 🗄️ NestGate (stores encrypted)
    └→ Results aggregated
    ↓
User receives complete secure pipeline results
```

**Security Properties Achieved**:


```
       ↓
Orchestration:      Songbird routes & coordinates
       ↓
Compute Layer:      ToadStool executes
       ↓
```


**Benefit**: No hardcoded endpoints, automatic failover, load balancing


## 🔄 Data Flow: Complete Security Audit Trail

### From User to Encrypted Storage

```
1. User → Songbird API
   POST /api/v1/compute/submit
   { "job_type": "secure_ml_training" }

2. Songbird → Capability Registry
   Query: services with "compute" capability
   → ToadStool found

3. Songbird → Capability Registry
   Query: services with "encryption" capability
   → BearDog found

4. Songbird → Capability Registry
   Query: services with "storage" capability
   → NestGate found

5. Songbird → ToadStool
   POST /api/v1/workloads/submit
   { "workload": "ml_training", "security": "encrypt_all" }

6. ToadStool → Training
   for epoch in 1..10:
     train()
     
     if epoch % 2 == 0:  # Checkpoint every 2 epochs
       ToadStool → BearDog
       POST /api/v1/crypto/encrypt
       { "data": checkpoint, "context": "ml_checkpoint" }
       
       BearDog → Encrypted checkpoint
       Returns: { "ciphertext": "...", "key_id": "...", "auth_tag": "..." }
       
       BearDog → NestGate
       POST /api/v1/storage/store
       { "data": ciphertext, "metadata": {"encrypted": true} }
       
       NestGate → Stored (zero-knowledge)

7. ToadStool → Final Model
   BearDog → Encrypt
   NestGate → Store encrypted

8. All Services → Songbird
   Report completion

9. Songbird → User
   { "status": "completed", "security": "encrypted", "storage": "zero_knowledge" }
```

**Every step traceable, auditable, secure!**
